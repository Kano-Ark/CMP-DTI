# LG-PCNet

Here is the code for paper **LG-PCNet: Multichannel Local–Global Collaborate from Molecular Point Clouds for Drug–Target Interaction Prediction**.

# System Requirements

The source code developed in Python 3.9 using PyTorch 2.4.0 The required python dependencies are given below. 

numpy==1.23.5

torch==2.4.0+cu124

scikit_learn==1.3.2

rdkit==2023.9.2

# Training

You can use main.py to train the model with dataset.
